# Project ownership and location

This folder is the master working copy for **Satisfactory - Early Locomotion**.

- Keep it in a normal user-controlled location such as `Documents`, not inside an AI-specific workspace.
- ChatGPT, Claude, Codex, Blender, Unreal Engine and other tools should all work from or reference this same project tree.
- `Design/GAME_DESIGN.md` is the editable design master.
- `Design/Early Locomotion Design Reference.docx` is the readable Word copy.
- `References/` is archival material and must not override the current design master.
- `Source/` will contain the actual Satisfactory mod project once development begins.
