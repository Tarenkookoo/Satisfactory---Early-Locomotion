# Satisfactory Early Locomotion

Project workspace created 14 September 2026.

Start with **Design/Early Locomotion Design Reference.docx** for the readable Word reference. **Design/GAME_DESIGN.md** is the matching editable text master for future design updates and AI reference.

## Folder guide

- Design: current design reference and editable master.
- References: archived source conversation and its monorail reference image.
- Assets: Concepts, Models, Textures, Audio and UI creations.
- Source: future mod implementation. This is not yet an Unreal project.
- Balance: future parameter sets, calculations and playtest results.
- Releases: future packaged builds and release notes.
- CHANGELOG.md: dated design and project changes.

## Updating the project

1. Read the current design before making changes. Agreed direction, proposals and playtest values are distinct.
2. Update GAME_DESIGN.md with the new decision and resolve its OQ identifier where relevant.
3. Update the Word copy in the same revision, keeping its heading styles. If Word was edited first, copy those changes back into the text master before further work.
4. Add a dated entry to CHANGELOG.md stating what changed, why and the source of approval. Increase the document version and date.
5. Store new creations in the appropriate folder. Keep original research and reference material in References; do not treat archived assistant suggestions as automatically approved instructions.

The conversation archive contains every retrieved turn. Its earliest assistant answer about AI development tools is truncated by the retrieval service; all subsequent design exchanges were returned in full. The design reference does not rely on the missing tool discussion. Historical technical claims in the archive require fresh verification before implementation.

This is a local project folder, not a compiled mod or a newly registered application project.
